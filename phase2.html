Switches & Switching Concepts

Key Concepts

  • Switches operate at Layer 2 and use MAC addresses to forward frames.
  • They maintain a MAC Address Table (CAM table) to know which device is on which port.
  • Support concepts like broadcast, unicast, and multicast communication.

Routers & Routing Fundamentals

Key Concepts

  • Routers operate at Layer 3 and determine the best path for packets.
  • Use routing tables to forward data between different networks.
  • Support static and dynamic routing protocols.

Wireless Networks

Key Concepts

  • Wireless networks use radio frequencies like 2.4GHz and 5GHz.
  • Access Points (APs) connect wireless devices to the wired network.
  • Security standards include WPA2 and WPA3.

Net work Topologies

Key Concepts

  • Topologies describe physical and logical arrangement of devices.
  • Common types: Star, Mesh, Bus, Ring, and Hybrid.
  • Star is widely used today because it is simple and reliable.

Cabling & Physical Media

Key Concepts

  • Includes copper (Ethernet), fiber optic, and coaxial cables.
  • Ethernet categories: Cat5e, Cat6, Cat6a, Cat7.
  • Fiber offers fastest speeds and long-distance communication.
