VLANs and Trunking

Key Concepts

  • Virtual Local Area Networks:found in layer 2 with which you can seperate big networks into smaller networks.
  • Prevents unnecessary traffic from reaching every device, enhancing performance and security.
  • VLAN trunking is separating switches so that network data flows to the correct subnetwork.
  • allows a single physical link to carry traffic for multiple VLANs.

Spanning Tree Protocol (STP)

Key Concepts

  • STP:It blocks redundant links between any two network devices and leaves a single active link between them so as to eliminate loops.
  • If an active link fails, STP selects a proper redundant link and places it in forwarding state to ensure network connectivity.
  • When spanning tree is enabled, all switches will send a special frame to each other called a BPDU
  • BPDU (Bridge Protocol Data Unit): contains the MAC address and the Priority together make up the bridge ID.

Routing protocols (OSPF, EIGRP, BGP)

Key Concepts

  • OSPF (Open Shortest Path First):is based on the SPF algorithm, which is used to calculate the shortest path for each node.
  • EIGRP (Enhanced Interior Gateway Routing Protocol):is defined as a distance-vector protocol to automate routing configuration and decisions on a network.
  • BGP (Border Gateway Protocol):is defined as a networking protocol to exchange routing data among autonomous systems.

Access Control Lists (ACLs)

Key Concepts

  • ACLs: is a set of rules defined for controlling network traffic and reducing network attacks.
  • they are used to filter traffic based on the set of rules defined for the incoming or outgoing of the network.
  • There are two types Standard Access-list and Extended Access-list

Quality of Service (QoS)

Key Concepts

  • QoS:is a network feature that sorts and prioritizes data, ensuring that essential activities like video calls get the necessary bandwidth and speed.
  • Measured Properties by QoS are Bandwidth, Latency/Delay, Jitter and Packet Loss
  • Advantages of QoS:Improved Network Efficiency, Reduced Latency and Jitter as VoIP and Enhanced User Experience
  • Disadvantages of QoS:Complexity and Potential for Resource Conflicts
